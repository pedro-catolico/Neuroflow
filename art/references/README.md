# REFERÊNCIAS DE ARTE — POLÍTICA E REGISTRO
## NEUROFLOW

---

## 1. POLÍTICA DE REFERÊNCIAS

### 1.1 Princípio Fundamental

O NEUROFLOW é um produto comercial original.

Toda referência visual utilizada durante o processo criativo deve ser:
- **Documentada** neste arquivo
- **Avaliada** quanto aos direitos de uso
- **Usada apenas como inspiração conceitual**, nunca como base para cópia

### 1.2 O que é Permitido

✅ Usar referências para compreender uma **sensação visual** ou **linguagem estética**  
✅ Usar referências para validar uma **direção artística**  
✅ Usar referências de obras em **domínio público**  
✅ Usar fotografias e obras com **licença Creative Commons** (documentar a licença)  
✅ Usar referências como **contraexemplo** (o que não queremos)  

### 1.3 O que é Proibido

❌ Usar obra protegida por direitos autorais como base para geração  
❌ Replicar o estilo de um artista identificável de forma direta  
❌ Usar personagens, logos ou marcas protegidos  
❌ Derivar obras de artistas vivos sem autorização explícita  
❌ Usar referências sem documentação  

### 1.4 Sobre Estilo Artístico

O estilo artístico em si não é protegível por direitos autorais — apenas a obra específica.

Portanto, é legal se inspirar no **conceito** do neurografismo como prática, desde que as imagens geradas sejam originais e não copiem obras específicas de nenhum artista.

## 2. REGISTRO DE REFERÊNCIAS

### 2.1 Formato de Registro

```
## REFERÊNCIA: [Nome/Título]
- **Tipo:** Conceitual / Técnica / Contraste / Domínio Público
- **Origem:** [Artista, fonte, URL]
- **Licença:** [Direitos autorais / Domínio Público / CC-BY / etc.]
- **Data de Acesso:** [data]
- **Uso:** [Como foi usada — apenas para inspir. conceitual, etc.]
- **Arquivos:** [Se algum arquivo foi salvo localmente]
```

## 5. AVISO SOBRE GERAÇÃO DE IMAGENS COM IA

Ao usar a ferramenta `generate_image` do Antigravity/Gemini:

- Os prompts são criados originalmente para este projeto
- As imagens geradas são criações originais baseadas nos prompts
- **Não usar** descrições de obras artísticas protegidas nos prompts
- **Não usar** nomes de artistas vivos como referência de estilo nos prompts
- Manter os prompts focados em **conceitos e técnicas** (fluido, orgânico, grayscale, etc.)
