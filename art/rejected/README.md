# REJECTED IMAGES — Arquivo de Rejeitadas
## NEUROFLOW

Esta pasta preserva TODAS as imagens rejeitadas durante o processo.

## Política de Preservação
**NUNCA apagar imagens desta pasta.**
Imagens rejeitadas são mantidas para:
- Referência histórica
- Aprendizado (identificar padrões de falha)
- Possível reavaliação futura
- Auditoria do processo

## Estrutura de Registro
Cada imagem rejeitada deve ter uma entrada no Illustration Master Plan com:
- ID da imagem
- Prompt usado
- Motivo da rejeição
- Data

## Critério de Entrada
Uma imagem entra em `rejected/` quando obtém status REJECTED no QA Visual:
- Texto ou watermark presente
- Média QA < 2.5
- Viola princípios fundamentais da Style Bible
