## Critério de Entrada
Uma imagem entra em `selected/` quando:
- Foi gerada em `generated/`
- Passou pela avaliação QA visual inicial
- Obteve status APPROVED ou REVIEW (para reteste de grayscale)
- O ID foi registrado no Illustration Master Plan
