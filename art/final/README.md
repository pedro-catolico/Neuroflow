# FINAL ART — Imagens Aprovadas para Produção
## NEUROFLOW

Esta pasta contém SOMENTE imagens que passaram por todos os critérios de aprovação.

## Critério de Entrada
Uma imagem entra em `final/` quando:
- ✅ Passou pelo QA Visual (média ≥ 3.5)
- ✅ Processamento grayscale aplicado
- ✅ Resolução ≥ 300 DPI verificada
- ✅ Sem texto, watermark ou artefatos
- ✅ Aprovada explicitamente para diagramação

## Convenção de Nomes
`NF-XXX.png` — sem espaços, sem caracteres especiais

## Uso
Arquivos desta pasta são usados diretamente na diagramação (`production/layouts/`).
Não modificar os arquivos desta pasta sem atualizar o registro no Master Plan.
