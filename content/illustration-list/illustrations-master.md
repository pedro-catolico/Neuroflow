## LEGENDA E ESTRUTURA DOS CAMPOS

| Campo | Descrição |
|-------|-----------|
| **ID** | Identificador único (NF-001 a NF-045) |
| **Título** | Nome provisório da ilustração |
| **Conceito** | Descrição da cena contemplativo-figurativa |
| **Motivo Principal** | Categoria do motivo (Human Female, Human Male, Human Group, Animal, Flora, Tree, Landscape, Water, Architecture, Object, Symbolic Composition) |
| **Modo Figurativo** | Tipo de protagonismo figurativo na cena |
| **Função Contemplativa** | Papel emocional e meditativo da imagem |
| **Complexidade** | Level 1 a Level 5 |
| **Composição** | Tipo compositivo (ver VARIATION_RULES.md v0.2.0) |
| **Fluxo** | Fluxo dominante de linhas |
| **Densidade** | Baixa / Média-Baixa / Média / Média-Alta / Alta / Muito Alta |
| **Integração Neurográfica** | Como o fluxo orgânico de linhas se estrutura e conecta os elementos da cena |
| **Densidade Figurativa** | Quantidade de elementos reconhecíveis na cena (Minimal / Low / Medium / High / Very High) |
| **Tonal** | Características de hierarquia de linha preta |
| **Experiência** | O que o colorista sentirá ao interagir com a página |
| **Status** | PLANEJADO / EM GERAÇÃO / GERADO / SELECIONADO / REJEITADO / FINAL |
| **Prompt** | Localização da ficha de rastreamento do prompt |
| **Arquivo** | Nome do arquivo gerado |
| **QA** | Avaliação QA visual |
